
# Financial Savings Calculator

This project is a 4-hour challenge to implement a basic calculator using Angular and C# .NET Core. The goal is to create a simple financial savings calculator with Angular as the front end and C# .NET Core as the API.

## Technologies Used

- **Front End:** Angular
- **Back End:** C# .NET Core

## Project Description

The Financial Savings Calculator is designed to help users calculate their savings over time. This project was developed as a quick challenge and might be continued later to add more features and improvements.

## Future Work

- Enhance the user interface
- Add more calculation features
- Improve API performance and security

## Getting Started

To get started with this project, clone the repository and follow the instructions in the respective front end and back end directories to set up the development environment.
